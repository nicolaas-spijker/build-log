# docs/

The depth layer of the brain. `CLAUDE.md` stays short and points here.
The agent opens these files only when a task needs them.

Two kinds of thing live here:

- **Reference** — material the agent reads when a task needs it: style
  guide, product detail, positioning notes, competitive intelligence.
- **Workflows** — the repeatable steps for a task, written down once so
  they run the same way every time. One file each, under `workflows/`.

Keep what you use. Delete the rest. Add files as the work needs them.
